# 03 · le montage (premiere pro + autocut)

la partie que les gens sous-estiment. le motion design impressionne, mais ce qui rend une
vidéo *regardable*, c'est le rythme du cut. et ça, c'est manuel.

## clair et net : le cut est 100% manuel

aucune ia ne décide de mon montage. je place chaque plan, chaque coupe, chaque respiration
à la main dans premiere. c'est là que se joue le rythme, et le rythme ne se délègue pas.

## le seul coup de pouce : autocut

[AutoCut](https://www.autocut.com/) est un plugin premiere (boîte française). je m'en sers
pour **le premier passage**, pas pour le montage final :

- **couper les silences** automatiquement sur la piste voix → gros gain de temps sur le dérush
- nettoyer les blancs, les "euh", les hésitations
- dégrossir un long rush avant de rentrer dans le montage fin à la main

en gros : autocut me donne un **brouillon propre** en quelques minutes. le vrai montage
commence après.

## comment je pose le montage

1. la **voix off** en piste de référence, c'est elle qui commande.
2. autocut passe sur la voix → les silences dégagent.
3. je pose les **rushes** et les **exports remotion** sur les bons mots.
4. je règle le **rythme** : couper un peu avant la fin d'une phrase pour garder le flow,
   laisser respirer sur un moment fort, accélérer quand ça traîne.
5. les illustrations remotion viennent **souligner** ce que dit la voix, jamais le répéter.

## le principe à retenir

premiere + autocut = **gagner du temps sur le mécanique, garder le contrôle sur l'artistique.**
autocut fait le sale boulot (les silences), moi je fais le montage. si tu attends d'un outil
qu'il "monte tout seul", tu seras déçu — c'est exactement le retour que j'ai eu de gens qui ont
essayé le montage full-ia.
